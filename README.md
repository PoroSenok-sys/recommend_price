# Исправление расчёта цены

Python 3.10 или новее. Дополнительные зависимости не нужны.

Два теста находятся в `starter.py`. Из папки с файлом запустите:

```sh
python3 -m unittest -v starter
```

Если установлен pytest, можно использовать `python3 -m pytest -v starter.py`.
Дополнительный плагин для асинхронных тестов не требуется.

Обычный запуск выполняет только пример:

```sh
python3 starter.py
```

Ожидаемый результат примера: цена `Decimal('4728.00')`, решение `APPLY`.

Вычисления выполняются через `Decimal`, со снижением цены на 1,5% и
округлением вниз до копейки. При сбое, тайм-ауте, неуспешном статусе или
отсутствии пригодных предложений сохраняется текущая цена (`HOLD`).
Изменение более чем на 30% возвращает рекомендуемую цену с решением
`REVIEW`; ровно 30% допускается (`APPLY`).

Тесты проверяют обычный расчёт и сохранение текущей цены при ошибке источника.
